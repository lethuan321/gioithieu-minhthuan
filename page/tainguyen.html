Tài nguyên online

Trang này gom các link học tập và công cụ frontend hay dùng. Các liên kết mở tab mới để bạn dễ tham khảo mà không rời khỏi website chính.

Học frontend

MDN Web Docs Tài liệu chuẩn về HTML, CSS, JavaScript và Web API. developer.mozilla.org W3Schools Ví dụ đơn giản, dễ tra cứu khi mới học frontend. w3schools.com Bootstrap 3 Docs Tài liệu đúng phiên bản Bootstrap website đang dùng. getbootstrap.com

Công cụ làm web

GitHub Lưu source code, quản lý phiên bản và chia sẻ dự án. github.com GitHub Pages Triển khai website tĩnh miễn phí trực tiếp từ repository. pages.github.com Favicon.io Tạo favicon nhanh cho website cá nhân. favicon.io

Thiết kế & nội dung

Google Fonts Kho font miễn phí để nâng chất lượng typography. fonts.google.com Coolors Tạo bảng màu nhanh khi muốn mở rộng giao diện. coolors.co Unsplash Ảnh tham khảo chất lượng cao cho mockup và bố cục. unsplash.com
